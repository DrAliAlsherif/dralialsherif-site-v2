أمن المعلومات والوثائق في البيئات الرقمية

Information & Document Security in Digital Environments

ورشة تؤسّس لفهم عملي لأمن المعلومات والوثائق في مؤسسات المعلومات: تصنيف المعلومات، ضبط الوصول، حماية الوثائق الرقمية وسلامتها، الخصوصية والامتثال، والاستجابة للحوادث — مع مواءمة الممارسات لمعايير مثل ISO 27001 وإدارة الوثائق ISO 15489.

مجال التدريبالأرشيف وأمن المعلومات
المستوىمتوسط
المدة المقترحةيومان تدريبيان (12 ساعة)
لغة التقديمالعربية
متطلبات سابقةالعمل في إدارة الوثائق أو الأرشيف أو النظم أو المكتبات الرقمية

1 أهداف الورشة

  • تصنيف المعلومات والوثائق حسب الحساسية ووضع سياسات التعامل معها
  • تصميم ضوابط الوصول (الهوية، الصلاحيات، مبدأ الحد الأدنى)
  • حماية سلامة الوثائق الرقمية ومنع التلاعب (التواقيع، البصمات، سجلّات التدقيق)
  • تطبيق مبادئ الخصوصية وحماية البيانات الشخصية والامتثال التنظيمي
  • وضع خطط النسخ الاحتياطي والاستعادة واستمرارية الأعمال
  • بناء خطة استجابة لحوادث أمن المعلومات وتسريب الوثائق

2 أهم محتويات الورشة

  • مفاهيم أمن المعلومات: السرية، السلامة، الإتاحة، وتطبيقها على الوثائق
  • تصنيف المعلومات وسياسات التعامل والتوسيم
  • إدارة الهوية والوصول: المصادقة، التفويض، مراجعة الصلاحيات
  • حماية الوثائق الرقمية: التشفير، التواقيع الرقمية، الطوابع الزمنية، سجلّات التدقيق
  • الخصوصية والامتثال: مبادئ حماية البيانات، الاحتفاظ، الإتلاف الآمن
  • التهديدات الشائعة: التصيّد، البرمجيات الخبيثة، الهندسة الاجتماعية، التهديد الداخلي
  • النسخ الاحتياطي والاستعادة واستمرارية الأعمال (BCP/DRP)
  • الاستجابة للحوادث: الاكتشاف، الاحتواء، التحقيق، الدروس المستفادة

3 مخرجات التعلّم

يُتوقَّع من المشارك بعد إتمام الورشة أن يكون قادرًا على:

  • يضع المشارك مخطط تصنيف معلومات وسياسة تعامل لمؤسسته
  • يصمّم مصفوفة ضبط وصول قائمة على الأدوار
  • يُعدّ خطة نسخ احتياطي واستعادة موثّقة
  • يبني دليل استجابة مبسّطًا لحوادث تسريب الوثائق

4 الفئة المستهدفة

  • أخصائيو ومديرو إدارة الوثائق والمحفوظات والأرشيف
  • مسؤولو النظم والمكتبات الرقمية
  • مسؤولو الامتثال وحماية البيانات في المؤسسات
  • فرق تقنية المعلومات المعنية بحماية المحتوى المؤسسي
