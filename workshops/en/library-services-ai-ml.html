Developing Library Services Using AI & Machine Learning Tools

تطوير خدمات المكتبات باستخدام أدوات الذكاء الاصطناعي والتعلم الآلي

The workshop looks at how AI and machine learning are reshaping library services: discovery and recommendation, automated reference service, content accessibility, user behaviour analysis and service personalisation — with practical applications and tools ready for gradual adoption.

Training areaArtificial Intelligence
LevelIntermediate
Suggested durationTwo training days (12 hours)
Delivery languageArabic
PrerequisitesExperience delivering library services; no advanced programming skills required

1 Workshop objectives

  • Identify the library services most open to improvement through AI
  • Design a simple recommendation engine for the library's resources and services
  • Build an automated reference assistant (chatbot) grounded in the library's knowledge base
  • Use machine learning on circulation and usage data to support decisions
  • Apply content accessibility tools: OCR, transcription, translation, alternative text
  • Evaluate new services through controlled trials and user satisfaction measurement

2 What the workshop covers

  • A map of library services and where AI and machine learning can improve them
  • Discovery and recommendation systems: principles, the data required, ready tools
  • The automated reference assistant: building the knowledge base, linking to sources, quality control
  • Usage analytics: data collection, predictive models, dashboards
  • Content accessibility and digital inclusion with AI tools
  • Service personalisation, privacy management and user satisfaction
  • An experimental method: control group, indicators, improvement cycle
  • A phased adoption plan and change management

3 Learning outcomes

By the end of the workshop, participants should be able to:

  • Design one AI-enhanced library service ready for trial
  • Build a prototype automated reference assistant or recommendation engine
  • Produce a dashboard for analysing service usage
  • Draw up an impact and satisfaction measurement plan for the new service

4 Who it is for

  • Public services, reference and user services specialists
  • Staff responsible for library systems, discovery layers and digital portals
  • Library data analysts and reporting officers
  • Managers of service and experience development in libraries
